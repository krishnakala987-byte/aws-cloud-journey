#  AWS Cost Optimization – Event Driven Serverless Automation

This repository contains a **real-world AWS Cost Optimization project** that focuses on identifying and removing **stale Amazon EBS snapshots** using an **event-driven, serverless architecture**.

The project demonstrates how **AWS Lambda, Python (boto3), IAM, and CloudWatch** can be combined to automate cloud resource cleanup and reduce unnecessary storage costs.

It is designed for **DevOps and Cloud engineers** to understand:
- How stale cloud resources increase costs
- How serverless automation helps in cost optimization
- How to build scalable and secure AWS automation using Lambda

Detailed explanations, concepts, and implementation notes are documented separately for learning and revision purposes.
