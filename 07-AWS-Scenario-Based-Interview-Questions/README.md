# AWS Scenario Based Interview Questions – EC2, IAM and VPC

This folder is my revision sheet of 10 scenario based questions on the topics covered so far. These are not definition questions. Each one describes a situation and expects a design or a decision, which is exactly how interviews test whether someone has actually done the work.

I wrote the answers in my own words after building most of these setups hands-on in the previous topics.

## Key takeaway
If I have really done the practicals, these questions feel like describing my own projects. If I have only watched videos, they feel impossible. That difference is the whole point of this repo.
