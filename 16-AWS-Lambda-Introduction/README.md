#  AWS Lambda – Introduction & DevOps Use Cases

This repository is focused on understanding **AWS Lambda from a DevOps perspective**.

It covers:
- What AWS Lambda is
- Why serverless architecture is used
- How Lambda differs from EC2
- Common DevOps use cases such as automation, cost optimization, and security
- Core concepts required to work with AWS Lambda in real-world environments

The repository includes **detailed learning notes** that explain AWS Lambda concepts step by step in a simple and beginner-friendly way, suitable for revision and interview preparation.

This project is part of my AWS learning journey and focuses on building strong fundamentals around **serverless automation using AWS Lambda**.
