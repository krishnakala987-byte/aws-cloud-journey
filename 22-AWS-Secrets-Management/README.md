#  Secrets Management – AWS & Enterprise Guide

##  About This Repository
This repository is a structured and practical reference for **secrets management in modern cloud and DevOps environments**.

It explains:
- Why secrets management is critical
- Problems with hardcoded secrets
- AWS-native secret management services
- Enterprise-grade secret management using HashiCorp Vault
- Clear comparisons and use cases

The goal of this repository is to serve as:
- A long-term learning reference
- A DevOps interview preparation guide
- A real-world production design handbook

---

##  Topics Covered

### 1. Fundamentals
- What secrets are
- Why secrets must never be hardcoded
- Common security anti-patterns

### 2. AWS Secrets Management
- AWS Systems Manager Parameter Store
- AWS Secrets Manager
- IAM-based access control
- Encryption and rotation concepts

### 3. Enterprise Secrets Management
- HashiCorp Vault overview
- Static vs dynamic secrets
- Short-lived credentials and TTL

### 4. Comparisons
- Parameter Store vs Secrets Manager
- Secrets Manager vs HashiCorp Vault
- When to use each tool
