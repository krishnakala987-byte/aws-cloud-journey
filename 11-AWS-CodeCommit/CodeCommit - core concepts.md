# AWS CodeCommit – Core Concepts

## What is AWS CodeCommit?
AWS CodeCommit is a fully managed source control service that hosts private Git repositories.

## Key Features
- Secure and scalable Git repositories
- IAM-based access control
- HTTPS and SSH authentication
- Regional service
- High availability

## Why Use CodeCommit?
- No infrastructure to manage
- Seamless AWS integration
- Enterprise-level security

## Region-Specific Nature
Repositories exist only in the region where they are created.
