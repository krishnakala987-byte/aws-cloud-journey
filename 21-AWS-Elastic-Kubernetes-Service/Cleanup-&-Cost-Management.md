# Cleanup and Cost Management

Cleanup was an important part of this project to ensure responsible cloud usage.

---

## Resources Deleted

- Application namespace
- Kubernetes Deployments and Services
- Ingress resources
- AWS Load Balancer Controller
- IAM service accounts and roles
- EKS cluster
- Fargate profiles

---

## Why Cleanup Matters

- Prevents unexpected cloud bills
- Reflects production discipline
- Essential skill for cloud engineers

---

## Final State

- No active EKS clusters
- No running compute resources
- No networking or load balancer resources

This ensured the AWS account was left in a clean state.
