# Kubernetes End-to-End Project on AWS EKS

This repository contains my end-to-end hands-on project on **Amazon EKS (Elastic Kubernetes Service)** where I deployed a containerized application using Kubernetes and exposed it using Ingress with AWS-managed components.

The objective of this project was to understand Kubernetes in a real cloud environment, not just deploy an application. The focus was on cluster setup, workload deployment, service exposure, ingress configuration, IAM integration, troubleshooting real issues, and finally cleaning up resources responsibly.

This project is part of my **AWS Cloud ** journey and reflects practical implementation and learning.

---

## What This Project Covers

- Amazon EKS cluster creation
- Kubernetes core concepts in AWS
- Application deployment using Kubernetes
- Service exposure using NodePort and Ingress
- AWS Load Balancer Controller integration
- IAM Roles for Service Accounts (IRSA)
- Debugging and troubleshooting real issues
- Complete cleanup and cost awareness

---

## Tech Stack Used

- Amazon EKS
- Kubernetes
- AWS IAM
- AWS Load Balancer Controller
- AWS Fargate
- eksctl
- kubectl

---

## Why This Project Matters

This project demonstrates real-world Kubernetes usage on AWS, including how different AWS services integrate with Kubernetes. It also shows ownership of the full lifecycle—from creation to cleanup—which is essential in production environments.
